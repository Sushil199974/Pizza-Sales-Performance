# 📊 Pizza Sales Data Analysis Dashboard

This project aims to analyze key performance indicators (KPIs) for pizza sales data and visualize important business trends using various charts. The goal is to derive actionable insights that can help optimize sales and inventory management.

## 🚀 Features

### 📌 **Key Metrics Calculated**
1. **Total Revenue** - Sum of total price of all pizza orders.
2. **Average Order Value** - Total revenue divided by the number of orders.
3. **Total Pizzas Sold** - Sum of all pizza quantities sold.
4. **Total Orders** - Count of all orders placed.
5. **Average Pizzas Per Order** - Total pizzas sold divided by the total orders.

### 📊 **Charts & Visualizations**
1. **Daily Trend for Total Orders** - Bar chart to track daily order fluctuations.
2. **Monthly Trend for Total Orders** - Line chart to analyze trends across months.
3. **Percentage of Sales by Pizza Category** - Pie chart to show distribution by pizza type.
4. **Percentage of Sales by Pizza Size** - Pie chart to analyze size-based sales trends.
5. **Total Pizzas Sold by Pizza Category** - Funnel chart comparing category-wise sales.
6. **Top 5 Best Sellers** - Bar chart for the highest-selling pizzas.
7. **Bottom 5 Best Sellers** - Bar chart for underperforming pizzas.

- **Power BI / Tableau** (if applicable) for interactive dashboards
- **SQL** for querying and data extraction
